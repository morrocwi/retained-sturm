# Contributing

This is a single-author showcase repository accompanying the "Retained Multilevel
Sturm" (RMS) paper and its benchmark/reproducibility artifacts.

- Issues are welcome — bug reports, reproduction problems, and questions about the
  benchmark methodology are all in scope.
- There is no PR template yet; this is not a software product with a formal
  release/contribution process, just a research showcase. If you'd like to submit a
  fix or an improvement, open an issue first to discuss it.
- No formal governance process beyond that at this stage.
